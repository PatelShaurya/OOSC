# UX4G Get Started Reference Notes

Source reviewed: [UX4G Get Started](https://www.ux4g.gov.in/get-started)

The reference establishes trust through a compact utility layer, clear accessibility controls, a restrained navigation system, and a direct headline followed by an explicit “choose your path” section. Its transferable patterns for Nyaya are a concise public-service entry point, explicit paths for different user intentions, strong information hierarchy, dark-mode access, and motion that supports state changes rather than decoration.

Nyaya adapts these principles without copying the visual brand or content: the public handoff explains the private workspace, the three landing paths lead to core civic tasks, the header offers accessible navigation and theme controls, and reduced-motion support remains active.
